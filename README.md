# 🚲 모두타 | 재배치 배송팀 앱

모두타의 공공자전거 재배치 업무를 맡은 배송팀 기사용 앱입니다.
기사는 관리자가 지시한 작업을 확인하고, 자전거가 많은 대여소에서 부족한 대여소로 자전거를 옮기거나 고장 자전거를 회수합니다.

> **개발 상태 · 기획 단계**  
> 2026년 11월 25일 기준, 배송팀 앱(D-1~D-3)과 관리자 웹의 배송팀 계정 발급·재배치 작업 지시(A-2·A-3)는 1차 MVP 범위에서 제외했습니다.

## 기획한 기능

| 구분 | 기능 | 기사가 하는 일 |
| --- | --- | --- |
| D-1 | 배송팀 로그인 | 관리자가 발급한 배송팀 계정으로 로그인합니다. |
| D-2 | 재배치 작업 수행 | 관리자가 지시한 작업을 확인하고 대여소 사이에서 자전거를 옮깁니다. |
| D-3 | 고장 자전거 회수 | 회수 대상 자전거를 확인하고 현장에서 수거합니다. |

## 관리자 웹과의 연결

관리자는 `admin-web`에서 배송팀 계정을 발급하고 재배치 작업을 지시합니다.
기사는 `worker-app`에서 해당 지시를 확인하고 현장 작업을 수행합니다.

## 협업과 검증

이 변경의 기준은 [공통 협업 규칙 개정본](https://github.com/MoDuTa/.github/blob/0f73a1af1716771f4b8ea62055ce777ae361db1b/CONTRIBUTING.md)입니다

- 작업 중 커밋 메시지는 강제 검사하지 않으며, Squash 최종 커밋에는 PR 제목을 사용합니다
